# Code of Conduct

## Scope

This code applies to all project spaces: the GitHub repository, issue
tracker, pull requests, and any other venue where project participants
interact as representatives of Pilot Protocol.

## Expectations

Participants are expected to:

- Be respectful and constructive in all interactions.
- Focus discussion on technical merit and project goals.
- Accept good-faith criticism and provide it in kind.
- Respect differing viewpoints and experience levels.

The following behavior is not acceptable:

- Harassment, personal attacks, or discriminatory language.
- Publishing others' private information without consent.
- Sustained disruption of project discussions.
- Conduct that a reasonable person would consider inappropriate in a
  professional setting.

## Enforcement

Violations can be reported privately to `founders@pilotprotocol.network`.
Reports are handled confidentially. The maintainers may issue warnings,
remove content, or ban participants from project spaces. The maintainers'
decisions are final.

## Attribution

This code of conduct is adapted in spirit from the
[Contributor Covenant](https://www.contributor-covenant.org/), simplified
for a small project.
